# E-Commerce Sales Performance Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing E-Commerce sales data using Microsoft Power BI to identify business trends, evaluate sales performance, monitor profitability, and generate actionable business insights.

The dashboard provides an interactive view of overall business performance through KPIs, charts, slicers, filters, and drill-through functionality.

## Key Features
- Sales, Profit, Profit Margin, Total Orders, and Average Order Value KPIs.
- Sales target tracking using Gauge Visual.
- Category-wise and product-wise sales analysis.
- Regional and state-wise performance analysis.
- Customer segment contribution analysis.
- Interactive slicers and filters.
- Drill-through analysis for detailed insights.
- Report Tooltips and Bookmarks.
- Business insights and recommendations.
